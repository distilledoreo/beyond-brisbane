Private group setup

Organizer only. Register exactly six travelers once, then everyone can sign in using just their first and last names. Names never appear in the public website's code or its leaderboard.

Allowed travelers

Enter each person's exact first and last name. Case doesn't matter—everything is automatically converted to CAPITAL LETTERS. To change the group later, enter all six names again; removed people will lose access, and their votes will be removed.

Privacy: The server stores only salted, secret-keyed identifiers for registered names, not the names themselves. The setup key is not stored in the website. Name-only sign-in remains easy to impersonate—someone who knows a registered person's full name can edit that person's vote.
